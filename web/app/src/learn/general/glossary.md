# Glossary

| Term | Meaning |
| --- | --- |
| AC-coupled, DC-coupled | A battery connected to the site AC bus through its own inverter, or to a shared DC bus through a DC/DC converter |
| aFRR, FCR, mFRR | Balancing reserves bought by the TSO: automatic frequency restoration, frequency containment and manual frequency restoration reserve |
| Aggregator | Company that bundles flexibility from many sites and sells it |
| Apparent power (kVA) and power factor | Voltage times current, the quantity that heats cables and transformers; real power (kW) equals apparent power times the power factor |
| Behind the meter | Everything on the customer's side of the grid connection |
| BESS | Battery energy storage system |
| BMS | Battery management system: measures, estimates, protects and balances the cells |
| BRP | Balance responsible party: keeps a portfolio's supply and demand matched |
| Calibration (of a forecast) | Agreement between stated probabilities and outcomes: a 90% quantile should be exceeded on about 10% of occasions |
| CC-CV | Constant-current, constant-voltage: the typical lithium-ion charging profile, with power tapering near full charge |
| Chance constraint | A limit that must hold with a stated probability, for example 95% |
| Contracted transport capacity | In the Netherlands, the maximum power a connection may draw at any moment in a calendar year under its contract |
| CPO | Charge point operator |
| CSMS | Charging station management system: the backend that controls chargers through OCPP |
| Digital twin | A virtual model of a site, calibrated on real data, used to test decisions before applying them |
| DOE | Dynamic operating envelope: time-varying import and export limits sent by a grid operator |
| Droop control | Decentralised control in which each converter lowers its voltage as its output current rises, so converters share load |
| DSO, TSO | Distribution and transmission system operators |
| EMS | Energy management system: software that controls a site's assets |
| Firm and non-firm connection | A firm connection is always available at full capacity; a non-firm one may be limited at times |
| Grid-forming, grid-following | Inverters that set their own voltage waveform, or that synchronise to the grid and control their current |
| ISO 15118 | Standard for communication between an EV and a charger, including Plug & Charge and, in part 20, bidirectional charging |
| LFP, NMC | Lithium iron phosphate, the dominant chemistry for stationary batteries; nickel manganese cobalt, common in long-range EVs |
| LP, MILP | Linear programming; mixed-integer linear programming, which adds yes/no decisions |
| MPC | Model predictive control: plan ahead with a model, apply the first step, replan |
| N-1 | Planning rule: the grid must withstand the loss of any single component without overloading the rest |
| OCPP | Open Charge Point Protocol, used between chargers and their backend; carries charging profiles (power or current limits over time) |
| P90 | Delivered at least 90% of the time |
| PCS | Power conversion system: the bidirectional inverter (or DC/DC converter) of a BESS |
| PIML, PINN | Physics-informed machine learning; physics-informed neural network |
| Pinball loss | The score used to train and evaluate quantile forecasts; it penalises errors asymmetrically |
| Revenue stacking | Earning from several value streams with the same asset |
| RL | Reinforcement learning: learning a control policy by trial and error |
| Scenario (forecast) | One possible future path of an uncertain quantity over the whole horizon |
| SEI | Solid electrolyte interphase: a thin film on the anode that protects it but slowly consumes lithium |
| SoC, SoH | State of charge (how full a battery is) and state of health (how much it has aged) |
| Time-block and time-duration rights | Dutch transport rights: transport only in agreed windows (regional grids), or for at least 85% of hours (TenneT grid) |
| V2G | Vehicle-to-grid: an EV feeding power back to the grid |
